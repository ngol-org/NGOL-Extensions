# AviUtl2 の演出サンプル

**ノードだけで演出を組み立てて確かめる見本。**
1 つの演出につき 1 つのフォルダで、それぞれ独立して動く。**5 例。**

見た目の種類を並べるためのものではない。**仕組みが違うものを 1 つずつ**置いてある。

## 一覧

| フォルダ | 何を示すか | ノード / 接続 |
|---|---|---|
| [text-with-border](text-with-border/) | 最小の 1 本。作る → 設定する → 表示する → 撮る | 5 / 3 |
| [midpoint-pause](midpoint-pause/) | 値を時間で動かす。中間点で動きを一拍止める | 8 / 6 |
| [layered-combo](layered-combo/) | 効果を何段も重ねる。実務に近い規模の組み方 | 18 / 16 |
| [stream-focus-lines](stream-focus-lines/) | 透過つきの素材を書き出す。ループ・出しっぱなし・一度きりの違い | 13 / 16 |
| [ngol-handoff-to-broadcast](ngol-handoff-to-broadcast/) | 書き出した素材を別のアプリのシーンへ載せ、色で確かめるまで | 6 / 9 |

**AI エージェントが MCP から使うことを前提にしている。**
どのフォルダも `graph.json` と `README.md` の 2 つ。

## 設定項目でつまずくところ

| 症状 | 実際 |
|---|---|
| ⚠ **オブジェクトが作られない**（`created` が false） | **効果を 1 つ間違えると、丸ごと拒否される。** 部分的に無視されるのではない。実例: `材質設定(カメラ制御)` をカメラ制御へ足した（正しくは**照らされる側**へ足す） |
| **書いた値と違う値が入っている** | **範囲を超えた値は黙って上限に丸められる。** 実例: `輝度::ゲイン=190` が `100` に、光源の `明るさ=320` が `200` に |
| **長い行が右で切れる** | テキストの既定は左寄せ。`文字揃え=中央揃え[中]` を書く |
| **変形率を上げても何も起きない** | `メッシュ変形` / `簡易変形` は `座標` が空だと効かない。格子の座標は画面で編集したときにしか入らない |
| **入れ子のキーがある** | `拡張色調補正` は `輝度::ゲイン` の形。平たい名前で書くと黙って無視される |

⭐ **効果を足したら `get_object_alias` で読み戻す。** 書いた値がそのまま残っているかで、
拒否・丸め・無視の 3 つがまとめて分かる。

## グラフの接続の書き方

```json
{ "fromNodeInstanceId": "a", "fromPortName": "items",
  "toNodeInstanceId": "b",   "toPortName": "value" }
```

| | |
|---|---|
| ⚠ **入れ子の形（`from: {instanceId, portName}`）は読まれない** | **実行は成功し、値が渡らないまま既定値で動いて `[OK]` が返る** |
| 実行順序だけを決めたいとき | 予約名 `__exec_in__` / `__exec_out__` を使う |
| 気づき方 | **WebUI で開くと線が 1 本も引かれない。** 実行結果からは分からない |

## レイヤーの向き

**番号が大きいほど手前。** そのうえで対象の向きが種類で逆になる。

| 置くもの | 対象になるのは |
|---|---|
| **フィルタオブジェクト** | **番号が小さい**（奥の）もの |
| **グループ制御・カメラ制御** | **番号が大きい**（手前の）もの。`対象レイヤー数` で枚数を決める |

⚠ **間違えても失敗として出ない。** 設定は入り、読み戻せば正しい値が返り、絵だけが動かない。

## 値を時間で動かす

```
X=-600.00,0.00,0.00,600.00,直線移動,0
   開始    中間 中間  終了   移動方法  パラメータ
```

| | |
|---|---|
| ⚠ 中間点はエイリアスでは作れない | **4 値を書いても 2 値に丸められる。** `create_object_section` で打つ |
| 点が無いのに 3 値を書くと | 値ごと捨てられて 0 になる |
| 中間点はオブジェクトが持つ | 1 つ打つと**すべての項目**が 3 値になる |
| 移動方法の名前 | 移動無し / 直線移動 / 直線移動(時間制御) / 補間移動 / 補間移動(時間制御) / ランダム移動 / 瞬間移動 / 移動量指定 / 反復移動 / 回転 |

## 効果には 3 つの性質がある

| 性質 | どうなるか | 例 |
|---|---|---|
| ふつうの効果 | 素材の後ろに積まれる | ほとんど |
| **素材を追い出す** | `[Object.0]` を占め、書いた素材が**消える** | 走査線 / カウンター / 周辺ボケ光量 / 雨 / 雪 / 雲 |
| **経過で進む** | 時間の項目を動かすと**かえって止まる** | 粒子化 / 砕け散る |

**見分け方**: 足したあと `get_object_alias` を読み、`[Object.0]` が自分の書いた素材のままか見る。
**回避**: かける側を別レイヤーのフィルタオブジェクトとして置く。

⚠ **`create_effect` は失敗を返さない。** 一覧に無い名前でも成功に見える。

## 覚えておくこと（どの例にも効く）

| | |
|---|---|
| 名前は列挙して確かめる | 効果名も設定項目名も `get_object_alias` で 1 往復でまとめて取れる。**推測しない** |
| ⚠ 書式を間違えたら | **作成は成功したまま、値だけ黙って捨てられる。** 書いたら読み戻す |
| カンマを含む値 | 書式が違うとホストが終わる。書式が確かなときだけ `allow_comma` を開ける |
| しきい値のある効果 | 発光・グローは既定 80。暗い素材は届かず、強さを上げても何も起きない |
| 階調の `幅` が狭いと | 2 色に割れる。連続した見た目にしたいなら画面の幅に近い値を |
| 発光を強くしすぎると | 縁が広がって塊になる。文字が読めなくなったらしきい値で絞る |
| 暗い効果は暗い地で見えない | 影・周辺ボケは明るい地を先に置く |
| 重ねる順序 | 万華鏡 -> 極座標 / ミラー -> 万華鏡。逆にすると対称が崩れる |
| ⚠ レイヤーが非表示だと | **置いても絵に出ない。しかもどこにも失敗が出ない** |

## ノードからは動かせなかったもの

実測で届かなかったもの。代わりの手があるものは併記する。

| | 状態 |
|---|---|
| **部分フィルタの範囲** | 位置も大きさも無視され、全面にかかる。マスクで代用する |
| **シーンチェンジ** | 置けるが切り替わらない。別のシーンと組で使うものらしく、シーンを編集する口が要る |
| **時間制御(オブジェクト)** | テキストには足せない |
| **万華鏡の回転** | 動かしても絵が変わらない。長さで代用する |
| **画像ループのオフセット** | 動かしても絵が変わらない。標準描画の座標で代用する |
| **クロマキー** | 基準色を指定し範囲を 400 まで広げても、色が 1 つも抜けなかった |
| **粒子化の逆再生** | `再生速度` を負にしても逆に流れない。進む向きで作る |
