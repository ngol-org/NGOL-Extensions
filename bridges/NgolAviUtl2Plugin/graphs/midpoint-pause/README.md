# 中間点で動きを一拍止める

## 何が出来るか

**左から入ってきた文字が、中央で一拍止まってから右へ抜ける。**

## 手順

```
1. 左から右へ動く文字を作る（値は 2 つ）
2. 30 フレームと 60 フレームに中間点を打つ（値が 4 つになる）
3. 真ん中の 2 つを同じ値にして、その区間だけ止める
4. フレームごとの値を並べて、止まっているか確かめる
5. 通しで動画にする
```

## 中間点の書き方

**トラックバーの値は、点の数だけ並べたあとに移動方法を書く。**

```
X=-600.00,0.00,0.00,600.00,直線移動,0
   |       |    |    |      |        |
   開始    中間 中間  終了   移動方法  パラメータ
```

| | |
|---|---|
| ⚠ 中間点はエイリアスでは作れない | **値を 4 つ書いても 2 つに丸められる。** 先に `create_object_section` で点を打つ |
| ⚠ 点が無い項目にカンマを書くと値ごと捨てられる | 中間点が 0 個なら値は 2 つまで。3 つ書くと **0 になる** |
| 点を打った直後の値 | ホストが等間隔に埋める。**書き換えないと、ただの直線移動と同じ** |
| 移動方法の名前 | 移動無し / 直線移動 / 直線移動(時間制御) / 補間移動 / 補間移動(時間制御) / ランダム移動 / 瞬間移動 / 移動量指定 / 反復移動 / 回転 |

### 絵を読まずに確かめる

`get_object_track_value` に `標準描画|X|90` を渡すと、フレームと値が並んで返る。

```
0:-600  9:-420  18:-240  27:-60  36:0  45:0  54:0  63:60  72:240  81:420  90:600
```

**36 から 54 まで値が動いていない。** ここが止めた区間で、動画を見なくても効いたと分かる。

## AI エージェントから使う

```
register_graph_from_file(filePath="<この README と同じ場所>/graph.json", open=false)
execute_fragment(graphId=<返ってきた id>, fragmentId="run")
   ...確かめる...
execute_fragment(graphId=<同じ id>, fragmentId="cleanup")
```

⚠ **`open` を省くとブラウザのキャンバスへ押し込まれ、他の人の未保存の編集を潰す。**

### 置いたものを必ず片付ける

⚠ **`cleanup` を忘れると、利用者の編集中のものに残る。**
断片が分けてあるのは、途中で確かめてから片付けられるようにするため。
