# 分割・揺らぎ・まとめて回す・カメラを重ねる

## 何が出来るか

**格子に割れて波打つ板と、下から噴き上がる粒が、ひとかたまりで回りながら、
さらにその全体を回り込むカメラから見える。**

## 手順

```
1. 板を作り、格子に割って波紋を足す
2. 別のレイヤーに粒を出すオブジェクトを置く
3. その 2 つより番号の小さいレイヤーにグループ制御を置き、まとめて回す
4. さらに小さい番号にカメラ制御を置き、目標中心回転で視点を振る
5. 通しで動画にする
```

## 覚えておくこと

| | |
|---|---|
| ⭐ **内側から外側へ順に積む** | 一番内が板の分割と揺らぎ、その外がグループ、一番外がカメラ |
| ⭐ 番号の付け方 | まとめる側ほど**小さい番号**。カメラ < グループ < 中身 |
| 対象の数 | グループは 2、カメラは 3（グループ自身も数に入る） |
| ⚠ 重ねるほど切り分けにくい | 動かないときは**内側から 1 段ずつ外して**どこで止まるかを見る |

### 絵を読まずに確かめる

`lit_by_frame` が**なめらかな山を描く**か。

```
0:0.1245  →  21:0.1472  →  38:0.1673(最大)  →  60:0.1297
```

⭐ 4 つの仕組みが同時に動いても、全体としては 1 つの山になる。
⚠ **どれか 1 つでも効いていないと、山が崩れるか平らになる。**

## AI エージェントから使う

```
register_graph_from_file(filePath="<この README と同じ場所>/graph.json", open=false)
execute_fragment(graphId=<返ってきた id>, fragmentId="run")
   ...確かめる...
execute_fragment(graphId=<同じ id>, fragmentId="cleanup")
```

⚠ **`open` を省くとブラウザのキャンバスへ押し込まれ、他の人の未保存の編集を潰す。**

### 置いたものを必ず片付ける

⚠ **`cleanup` を忘れると、利用者の編集中のものに残る。**
断片が分けてあるのは、途中で確かめてから片付けられるようにするため。
