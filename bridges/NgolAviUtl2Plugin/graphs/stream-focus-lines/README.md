# 配信で重ねる素材（stream-focus-lines）

**思いついた効果を、その場で作って、別のアプリの画面へ重ねる。**
驚いた・強調したいときに出しっぱなしで使う見本。1 本のグラフで
「作る -> 透過つきで書き出す -> 相手のシーンへ載せる -> 数で確かめる」まで通る。

## 他の見本との違い

効果そのものの見本は他に 80 本以上あるが、**どれも背景つきで重ねられない**。
重ねるには 3 つ要る。

| 要件 | どうするか |
|---|---|
| **透過** | 書き出しで `keep_alpha` を立てる。落とすと四角い板になる |
| **ループ** | 末尾が先頭に戻る作りにする。戻らないものは繰り返さない |
| **すぐ載る** | グラフ 1 本で相手のシーンまで通す |

## 出しっぱなしと一度きりで、設定が変わる

| | `looping` | `clear_on_media_end` |
|---|---|---|
| 出しっぱなし | `true` | 終わらないので影響なし |
| **一度きり** | `false` | ⚠ **`true` にする** |

⚠ **一度きりで `false` にすると、再生し終えた最後の 1 枚が画面に残り続ける。**
止まった絵が出たままになり、素材のファイルをいくら調べても分からない
（ファイルは正しく、残るのは受け手側の設定のため）。

## ループさせたいのに動かす手が要るとき

`直線移動` は確実に効く。⚠ ただし始点から終点へ進むだけなので、末尾と先頭が繋がらない。

⭐ **前半と後半で向きを逆にした 2 つを並べる**と繋がる。

```
frame=0,29   強さ=40 -> 420   直線移動
frame=30,59  強さ=420 -> 40   直線移動
```

⚠ `反復移動` は末尾の値を変えても動かせなかった。効かせ方は未解明。

## 場を片付けてから書き出す

**書き出しは画面全体を描く。** ⚠ 他の見本が同じ画面に残っていると混ざる。

⚠⚠ **混ざっても失敗に見えない。** 別の素材が出来上がるだけなので、
1 本だけ見ていると気づけない。⭐ **複数まとめて測ると、値が同じになることで分かる。**

**レイヤー 16〜19** はこの系統の見本のための予約領域で、実行の最初に 4 つとも消してから自分の使う分だけ出す。

## 差し替えるところ

| | |
|---|---|
| `alias` | 効果の中身。⚠ 効果名は推測せず、他の見本から写すか、ホストに列挙させる |
| `output_path` / `encoder_path` | 書き出し先と符号化の道具 |
| `name_contains` | 相手の名乗りに含まれる文字 |
| `match_color` | 判定に使う色。素材に 1 色だけの目印を置いておく |
