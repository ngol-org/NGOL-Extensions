# テキストを置いて縁取りにする

## 何が出来るか

**黄色の縁取り文字が、画面の上寄りに出る。**

## 手順

```
1. エイリアスでテキストを作る（色・縁取り・位置をその中で決める）
2. 文字装飾 を読み戻して、書いた値が入ったか確かめる
3. 絵にする
```

## 覚えておくこと

| | |
|---|---|
| 選択項目 | **表示名をそのまま書く**（`文字装飾=縁取り文字`）。番号ではない |
| 色 | 16 進 6 桁（`ffcc00`） |
| 長さ | `frame=0,60` が開始と終了 |
| ⚠ 書式を間違えたら | **作成は成功したまま、値だけ黙って捨てられる。** 読み戻して確かめること |

⭐ 書き方が分からない項目は、**似たものを 1 つ作って `get_object_alias` で読む**のが早い。
ホスト自身が書いた表記がそのまま出るので、推測しなくてよい。

## ⚠ 使うレイヤーを先に表示させている

**レイヤーが非表示だと、置いても絵に出ない。** オブジェクトは正しく作られ、
設定値も読み戻せるのに、絵だけが空になる。⚠ **どこにも失敗が出ない。**

⭐ **開いていたプロジェクトの状態がそのまま残る**ので、見本の側で毎回そろえる。

⭐ 気づけたのは `lit_ratio` が 0 だったから。**数で確かめる形にしていなければ、
「なぜか出ない」で止まっていた。**

---

## AI エージェントから使う

```
register_graph_from_file(filePath="<この README と同じ場所>/graph.json", open=false)
execute_fragment(graphId=<返ってきた id>, fragmentId="run")
   ...確かめる...
execute_fragment(graphId=<同じ id>, fragmentId="cleanup")
```

⚠ **`open` を省くとブラウザのキャンバスへ押し込まれ、他の人の未保存の編集を潰す。**

### 絵を読まずに確かめる

**画像を見るのに掛かる量は画素数で決まる**（中身が黒ばかりでも同じ）。
⭐ まず数で確かめ、**食い違ったときだけ**絵を見る。

`aviutl.edit.object_item` が `縁取り文字` を返す。`capture_canvas` の `lit_ratio` は 1% 前後（文字だけなので小さい）

### 置いたものを必ず片付ける

⚠ **`cleanup` を忘れると、利用者の編集中のものに残る。**
断片が分けてあるのは、途中で確かめてから片付けられるようにするため。
