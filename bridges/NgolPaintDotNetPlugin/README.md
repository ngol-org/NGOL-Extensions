# ホストが最初から .NET のときのブリッジ（画像編集ソフト Paint.NET）

ホストが読みに来るフォルダへ **DLL を 1 枚**置くと、NGOL が同じプロセスで起きる。外せば元に戻る。

```
Paint.NET (paintdotnet.exe / .NET 9 を同梱)
 └── FileTypes\NgolForPaintDotNet.dll      ← ホストが起動時に構築する型が 1 つあるだけ
       └── NgolRuntime.Initialize(ngolRoot)
             └── NGOL 一式（ノード・WebUI・解析拡張）
```

⭐ **他の 3 本との違いはここだけ。** ホストが最初から .NET なので、
**hostfxr も C++ も `NgolActivator` も出てこない**。ネイティブと .NET の境界が無いので、
`[UnmanagedCallersOnly]` も関数ポインタも要らない。

```
ネイティブのホスト:  ホスト → C++ → hostfxr → NgolActivator → NgolRuntime
このホスト:          ホスト → 型が構築される → NgolRuntime
```

---

## まず最初にすること

載せただけでは画面に何も出ない（意図的にそうしてある）。**MCP から次のノードを 1 回実行する。**

```
run_node  pdn.ui.webui_button
```

MCP が無ければ、`http://localhost:11156/` をブラウザで開いて出る編集画面から
同じノードを 1 回実行してもよい。

ホストのツールバーへ虫眼鏡のボタンが増える。以後はそこから WebUI・保存済みグラフ・
下の各ノードを呼べる。⚠ **ホットリロードで `.cs` を直しても、ボタンは足した時点のコードを
握ったまま**なので、直したら同じノードをもう一度実行して入れ直すこと。

## 何ができるか

**すべて実測。**「届く」は、その操作を実際に行い、別の手段で結果を確かめたもの。

| やりたいこと | 届く手 | 実測 |
|---|---|---|
| ホストの素性を読む | `pdn.app.info` | 版・主ウィンドウの題・登録されている効果の数・**このブリッジ自身が公式の一覧に載っているか** |
| 何が入っているか棚卸し | `pdn.plugins.list` | 管理側（公開/総数）とネイティブ側を 1 表に |
| 開いている画像 | `pdn.doc.info` | 大きさ・レイヤー数・名前 |
| ツールウィンドウの置き場所を覚える | `pdn.tools.remember_layout` | **画像ごとに記憶して戻す**。ホストに無い機能で、再起動しても残る |
| ツールバーへメニューを足す | `pdn.ui.webui_button` | 上記のボタン。項目はノードを直接呼ぶ |
| **組み込み効果へ機能を足す** | `pdn.fx.extend` | 効果のダイアログへ**色ごとのつまみ**を 3 本足す。色収差のような縁が出る。効果は `effect` で選ぶ（シャープ・ぼかし（移動）・ぼかし（ガウス）・すりガラス）。⭐ **倍率が 3 つとも 1.0 なら、ホストの出す絵とビット単位で一致**（差 0.00） |

⭐ **届き方が 2 通り混ざっていることに意味がある**——一部は参照できる公開 API、
一部は反射。読者が自分のホストで書くときとまったく同じ構図になる。

### 手を入れた所が見て分かる

ホストの機能へ後から足したものは、**足したことが見えないと利用者が困る**——
どこまでがホストの機能で、どこからが後付けかが区別できない。
このホストには**その区別を表す仕組みが既にある**ので、それを借りる。

| 出る所 | 何が出るか | 借りている仕組み |
|---|---|---|
| 効果メニュー | 項目の右端にホスト自身のプラグインの印。指すと何を足したかが出る | メニュー項目が持つ「これはプラグインか」の値。**読まれるのは項目を描く所 1 か所だけ**なので、並び順や分類は動かない |
| 調整ウィンドウ | 足したつまみの手前に区切り線と `NGOL Extended` の 1 行 | 値を書けない札の部品。名前を空白 1 文字にすると線だけが端まで通る |

⭐ **どちらもホストが元から持っている口で、描画には手を入れていない。**
パッチを外せば両方とも元に戻る。

印の絵はホスト自身のリソース（`Icons.PluginIndicator`）で、描画側が
**プロセスに 1 つだけ**持ち、型の初期化時に読み込んでいる。第三者のプラグインも
この絵を持ち込んでいるわけではなく、ホストが全員に同じものを描いている。
⭐ **こちらが同梱している画像は 1 枚も無い**——立てるのは真偽値 1 つだけ。

## 置き方

ホストを閉じてから配置スクリプトを呼ぶ。**起動時に 1 回だけ走査するので、開いたままでは反映されない。**

```powershell
./scripts/deploy.ps1 -PluginBinary <NgolForPaintDotNet.dll> -NgolRuntime <repo>\build\runtime
```

置かれるもの:

```
%USERPROFILE%\Documents\paint.net App Files\
    FileTypes\NgolForPaintDotNet.dll     ホストが走査するのはここ
    ngol\                                NGOL 一式（走査の外に置く）
        Nodes\CustomNodes\cs\            このホスト向けのノード
        Graphs\                          デモのグラフ
```

外すときは `-Clean`。DLL を消してホストを起動し直せば、何も残らない。

### ⚠ NGOL 一式を `FileTypes\` の中へ置かない

ホストはそのフォルダを走査するので、**NGOL 自身をプラグインとして読もうとする**。
隣（`..\ngol`）へ置き、プラグインから相対で解決する。

## 入口の選び方

⭐ **ホストが起動時に構築してくれる型を 1 つ用意すればよい。種類は選べるので、
UI に何も出さないものを選ぶ。** ここでは「ファイル形式の生成器」を使い、形式を 1 つも返さない。

| 入口 | 起動時に構築されるか | UI への足跡 |
|---|---|---|
| モジュール初期化子 | ⚠ **走らない**（型の数え上げは反射なので、コードは動かない） | — |
| プラグイン情報 | 走らない（一覧を開いたときだけ） | 一覧に作者・版 |
| 効果の型 | 走る | ⚠ **効果メニューに並ぶ。押すと開いている画像がその出力で置き換わる** |
| **ファイル形式の生成器**（採用） | **走る** | **無し** |

⭐ **このホストには「起動時に呼ばれる」種類のプラグインが無い。それでも載る。**
読者のホストにその口があるなら、もっと楽に済む。

## ホスト自身のスレッドで回す

ノードがホストの型に触ってよいのは、そのホストのスレッドだけ。読み替えるのはこの表の列だけ。

| | このホスト | 読者のホスト |
|---|---|---|
| ホスト自身のスレッド | UI スレッド | 更新ループのスレッド |
| そこへ乗る手段 | `Application.OpenForms` の主ウィンドウへ `BeginInvoke` | 毎フレーム呼ばれる口 |
| NGOL 側の設定 | `EnableDirectMode=false` ＋ `Tick()` | 同じ |

## 組み込み効果へ機能を足すときの制約

`pdn.fx.extend` が踏んだもの。**同じことをするなら先に読む価値がある。**

⭐ **組み立ての形は 2 つしかない。** 効果ごとにノードを写経せず、表に 1 行足せば増える。

| 形 | 何をするか | 該当 |
|---|---|---|
| **split** | 絵を 3 本へ枝分かれさせ、ホストの部品の写しを色ごとに違う強さで走らせ、1 色ずつ取り出して足し戻す。締めの部品が要る効果は、最後にもう 1 つだけ写しを置く | シャープ・ぼかし（移動）・ぼかし（ガウス） |
| **blend** | 歪み系は枝分かれできない。ホストの出す絵をそのまま材料にして、元の絵との混ぜ具合を色ごとに変える | すりガラス |

| | |
|---|---|
| 調整ウィンドウ | WinForms を組むのではなく、効果が返す「何を持つか」「どう見せるか」から**ホストが生成する**。返り値を差し替えれば増やせる |
| 描き直し | ⚠ **足した設定だけが動いてもホストは描き直さない。** 変化の判定を掴んで引き上げる |
| 枝分かれできる効果 | **ぼかしのような普通の効果は 3 本並べられる。** 色ごとに独立した線形処理なので、色を分けて足し戻せば元に戻る |
| 歪み系の効果 | ⚠ **枝分かれさせて元絵を分け合うと、絵が升目状に描き落とされる。** 直列に繋ぐ分は通る。⭐ **同じ手が使えるかは効果の種類で決まる** |
| 見分け方 | ⭐ **`OnCreateOutput` を読めば一目で分かる**——`PdnDistortionEffect` の入口を使っていれば歪み系。GPU 効果 55 本のうち 8 本（`Bulge` / `Crystalize` / `Dents` / `FrostedGlass` / `PolarInversion` / `RotateZoom` / `TileReflection` / `Twist`）がそれで、残りは枝分かれできる |
| 色の重み | ⚠ **8 ビットの premultiplied では色は透明度を超えられない。** 透明度を割合で下げると、**触っていない色まで削られる** |

⭐ **どれも「動かない」ではなく「静かに違う絵になる」形で出る。** 数える器を先に置くこと。
